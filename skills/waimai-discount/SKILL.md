# 外卖优惠助手 (Waimai Discount)

根据用户想点外卖的场景，推荐各平台**官方领券渠道**并给出领取路径。数据为官方入口指引，**不含任何 CPS 返佣链接**。

## 执行流程

### 步骤 1：理解用户意图

提取「平台」（美团 / 饿了么 / 京东外卖 / 淘宝闪购）与「券类型」（红包 / 新客 / 学生 / 满减 / 神券包 / 返现）关键词。

### 步骤 2：调用查询脚本

```bash
node scripts/find.mjs "<用户查询>" --limit=10
# 列全部渠道概览
node scripts/find.mjs --list
# 程序化调用
node scripts/find.mjs "学生" --format=json
```

脚本位于 `D:\Projects\waimai-discount\`（相对本 SKILL.md 的 `scripts/find.mjs`）。

### 步骤 3：返回结果

将脚本输出整理为简洁回复，包含：平台 + 渠道名 + 券类型 + 领取路径（App 内路径 / 小程序 / 支付宝淘宝入口）。

## 领券策略建议（下单前）

- **三券叠加**：平台券（天天神券/天天领红包）+ 店铺券 + 满减，三管齐下最省
- **新客/学生专用**：力度最大，先引导用户到对应认证页领取
- **比价**：同一餐在美团 vs 饿了么 vs 京东外卖的券后价可对比后下
- **时段**：午/晚高峰券量足，跨天 0 点后券刷新，可提示用户隔天再领

## 数据来源与更新

- 渠道目录：`data/channels.json`（长期稳定的官方入口指引，无时效性返佣数据）
- 具体活动力度以 App 内实时展示为准；提示用户下单前核对

## 可选自动化（需授权）

用户明确同意且已登录对应 App 时，可调用浏览器/CDP 打开领券页辅助领取；**不代付、不自动下单、不读取账户资金信息**。
